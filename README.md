# Resurrection Fest EG 2026

Agenda offline para iPhone.

## Publicar en GitHub Pages

1. Crear un repositorio publico llamado `resurrection-fest-2026`.
2. Subir estos archivos a la rama `main`.
3. En GitHub: `Settings > Pages > Build and deployment`.
4. Seleccionar `Deploy from a branch`, rama `main`, carpeta `/root`.
5. Abrir la URL de Pages una vez en Safari del iPhone.
6. Esperar unos segundos, activar modo avion y comprobar que sigue cargando.
7. Usar `Compartir > Anadir a pantalla de inicio`.

Para forzar actualizaciones offline, cambia `CACHE_NAME` en `sw.js`.
